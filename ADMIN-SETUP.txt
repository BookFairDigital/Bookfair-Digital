ADMIN LOGIN SETUP

1. Firebase Console → Authentication → Sign-in method → Email/Password → Enable.
2. Firebase Console → Authentication → Users → Add user.
3. Create the administrator email + password there.
4. Open /admin-login.html to sign in.
5. Successful sign-in redirects to /admin.html.

SECURITY NOTE:
A signed-in user is not automatically an admin. For production, enforce admin authorization
with Firebase custom claims / a trusted backend and Firestore rules. Never put an Admin SDK
service-account private key in GitHub Pages.
